## ⚠️ 免责与使用说明

* **质量与时效：** 资料**无法保证是最新版本**。本项目只侧重于我自己的收集，内容的准确性和时效性可能不会很好，请自行甄别、理性参考。
* **内容偏向：** 编者为**电气专业**学生，因此资料可能多是电气专业相关的资料。如果看到了其他专业的资料，也会顺手丢进来。
* **更新频率：** 本项目基于个人实际需求进行**随缘更新**。只要我有需要，就会不定期往里补充。
